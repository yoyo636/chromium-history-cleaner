隐私政策 Privacy Policy

适用扩展：浏览器搭子 · 历史与标签页管家（Browser Companion）
版本 v4.2 · 生效日期：2026 年 8 月 31 日
开源仓库：github.com/yoyo636/chromium-history-cleaner
重要声明：本扩展不在任何服务器上收集、存储、传输或出售任何用户数据。 所有数据处理均在您的本地设备（浏览器）内完成。扩展不含分析/广告 SDK、追踪器或第三方代码，也不加载外部 CDN。

一、我们收集与处理的数据

本扩展仅在您主动操作对应功能时，通过浏览器官方 API 读取本地数据，用于实现您所请求的功能。具体如下：

数据类别用途是否离开设备
浏览历史（时间 / 标题 / URL）「历史」查询、删除、导出；「统计」访问分析否
标签页信息标签批量关闭、去重、会话存档否
书签数据去重、死链检测、导出、删除否
下载记录下载管理；清理页显示真实占用否
浏览数据（缓存 / Cookie / 历史等）仅在你确认后清除；不读取不保存内容否
会话存档（URL 列表）会话保存 / 恢复，存于扩展本地存储否
网页交互信号（鼠标 / 滚动 / 键盘节奏 / 长任务 / 帧率）护眼与性能模块本地计算否
指纹调用事件（Canvas / WebGL 读取）隐私模块本地报告与一键加固否
偏好设置主题 / 时间范围 / 开关，存于扩展本地存储否

明确不收集：姓名、邮箱、账号、密码、支付信息、真实身份等任何可定位到个人的标识。

二、无痕（隐身）模式说明

无痕模式下产生的记录同样仅存于本地，并按浏览器无痕规则处理。「隐私」模块会标注指纹调用是否发生在无痕模式，帮助您识别试图穿透无痕的站点。注意：无痕模式本身无法阻止指纹识别，「一键加固」可在本地随机化 Canvas / WebGL 指纹以降低风险。

三、数据的存储与保留

  • 扩展数据（偏好、会话、疲劳曲线、隐私事件、性能快照）保存在浏览器本地 chrome.storage.local，不上传任何远程服务器。
  • 浏览器内置数据（历史、书签、下载）由浏览器自身管理。
  • 您可随时：在「隐私」页清空记录、在「会话」页删除存档；卸载扩展即清除全部本地数据。

四、数据共享与第三方

  • 不向任何第三方出售、出租或共享数据；本扩展无服务端，开发者无法接触您的数据。
  • 无第三方分析 / 广告 / 崩溃上报 SDK；代码全部内嵌，不加载外部脚本或 CDN。
  • 插件自身发起的网络请求仅一类：书签「死链检测」对书签 URL 发起 HEAD 探测（仅传输该 URL 本身）。

六、儿童隐私

本扩展不面向 13 岁以下儿童设计，不故意收集儿童个人信息。

七、政策变更

政策变更将在本页面与商店页面同步更新并标注新的生效日期。
