🧭 浏览器搭子 · 安装指南

版本 4.6.0 · 安装位置 %LOCALAPPDATA%\BrowserCompanion

一、安装完成后发生了什么

✅ 扩展文件已安装到本机（含全部 13 个功能模块：历史清理、护眼引擎、专注模式等）

如果安装最后一步勾选了「运行重新载入扩展」，你的浏览器会自动带着扩展启动 —— 右上角出现 🧭 图标即安装成功，无需其他操作。

二、浏览器里没有看到扩展？手动载入（3 次点击）

部分新版浏览器（如 Chrome 正式版）出于安全策略限制自动载入，此时手动载入一次即可，以后一直有效：

  1. 地址栏输入 chrome://extensions（Edge 为 edge://extensions）并回车
  2. 打开右上角（Edge 在左侧）的「开发者模式」开关
  3. 点「加载已解压的扩展程序」，选择文件夹：
    %LOCALAPPDATA%\BrowserCompanion\extension

出现「开发者模式扩展」提示气泡属正常，点 ✕ 关闭即可。

三、日常使用

  • 点浏览器右上角 🧭 图标打开主面板（13 个功能都在里面）
  • 升级：重新运行安装包覆盖安装后，到 chrome://extensions 点扩展卡片上的刷新按钮 🔄
  • 篡改 / 专注 / 广告拦截等功能说明见项目内 ALGORITHM.md 与各模块内提示

四、卸载

开始菜单 → 「BrowserCompanion」→「卸载」；然后到 chrome://extensions 移除扩展卡片。

五、为什么需要手动载入这一步？（技术说明）

Chrome / Edge 的安全策略规定：第三方安装程序不能把扩展直接注册进浏览器，只有官方商店或企业管理员策略可以。所以「安装包 + 一次性手动载入」是自分发扩展的标准形态。如果以后把扩展上架 Chrome 商店，就可以做到完全静默安装（注册表外部分发），届时更新安装包即可。
