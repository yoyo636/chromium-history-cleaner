Features

十八个模块，各司其职

每个模块都为「真实可运行」而设计——没有占位符，没有注水代码。

🚫

广告拦截

declarativeNetRequest 网络层拦截（浏览器原生匹配，零 JS 开销）：191 条广告 / 追踪规则，分站白名单与自定义规则，残留占位框自动隐藏。

📜

历史管理

按时间范围全量查询（突破 API 千条限制）、实时过滤、多选 / 单条 / 按段删除、JSON / CSV 导出。

🗂️

标签管家

批量关闭、去重、按域名关闭、复制网址、会话存档——乱糟糟的标签页一键归位。

👁️

护眼引擎

自研「观息」疲劳引擎：鼠标 / 滚动 / 键盘节奏 → Welford 在线统计 + P² 分位估计 → 1–5 级疲劳，30 秒渐进调整排版。

⚡

性能透视

每标签 CPU 繁忙度、堆内存、帧率一目了然；一键冻结或关闭高耗能标签，持续高负载预警。

🛡️

隐私加固

监控 Canvas / WebGL 指纹调用、跨站追踪图谱，一键随机化指纹输出——全部在本地完成。

🔊

音频静音

识别所有发声标签，频谱分类（人声 / 音乐 / 广告），智能静音 + 域名记忆。

🔖

书签去重

按网址去重、死链 HEAD 探测、导出 JSON / HTML。

🧹

数据清理

先扫描真实磁盘占用（含下载 GB 数），经确认后清理缓存 / Cookie / 历史，清理后自动复扫验证。

📊

访问统计

Top 域名与页面条形图，7 / 30 / 90 天或全时段。

🎯

专注模式

威胁评分 + 时段敏感性 + 强化学习提醒时机；事件回放时间轴、分心原因速记。

💾

会话存档

恢复最近关闭的标签 / 窗口，自定义会话随时存取。

⬇️

下载管理

查看、打开文件 / 所在文件夹、按条件移除记录。

📄

文章下载

把当前网页提取为自包含 HTML（含图片内联），离线可看，一键保存到本地。

❤️

健康分

浏览器体检：综合使用习惯给出 0–100 健康分与改善建议。

🏠

房地产工具

房贷 / 税费 / 租金回报计算，土地面积单位换算。

🔧

开发者·篡改

数据修改工具（需密码解锁），用于调试与测试。

⚙️

偏好设置

主题（跟随系统 / 亮 / 暗）、历史默认范围、清理二次确认开关。
